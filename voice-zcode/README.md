# Голосовой интерфейс ZCode

Голосом и текстом — в **одном и том же диалоге** ZCode. Демон живёт в трее.

## Как пользоваться

**Способ 1 — надёжный, hold-to-talk:**
зажми **Ctrl+Alt+Пробел**, скажи команду, отпусти — текст появится в поле
ввода ZCode и отправится. Окно ZCode найдётся само (даже если фокус в другом
приложении — оно выйдет на передний план).

**Способ 2 — руки свободны, слово «рабочая голова робота»:**
скажи **«зета, …»** — пик — и говори команду; после паузы ~1.3 с второй пик,
дальше то же самое. Слово проверяет связка vosk (лёгкий, постоянный) +
whisper-перепроверка сомнительных фраз (vosk часто слышит «зету» как
«зато»/«за это», whisper понимает верно и подтверждает).

**Куда попадает команда:**
- окно ZCode открыто (практически всегда) → вставка + Enter в тот же диалог,
  где ты печатаешь;
- окна ZCode нет вообще → общий голосовой ассистент без привязки к проекту,
  ответ озвучится (нейроголос Svetlana, офлайн-фолбэк Irina).

Меню трея: «Слушать сейчас» (говорить до паузы) · «Слушать „голова робота"» вкл/выкл ·
«Новый диалог» (следующая голосовая фраза начнёт чистую ветку ассистента) ·
«Выход». Двойной клик по значку ничего не запускает — случайно не нажмётся.

## Запуск и автозапуск

- Ярлык на рабочем столе: **«Голосовой ZCode»**.
- В автозагрузке (shell:startup): демон и приложение ZCode.

## Настройка — `settings.json`

| Ключ | Что делает |
|---|---|
| `wake_word` / `wake_enabled` | Слово-активатор и вкл/выкл прослушки |
| `wake_verify` / `wake_whisper` | Перепроверка wake whisper-ом (модель) |
| `hotkey` / `hotkey_enabled` | Hold-to-talk комбинация |
| `mic_name` | Подстрока имени микрофона; `null` — системный (в логе видно какой) |
| `whisper_size` | `medium` — точность; `small` — быстрее |
| `paste_submit` | Вставлять сразу с Enter или только в поле |
| `endpoint_silence_ms` | Тишина, завершающая команду |

## Диагностика

Лог `voice.log` пересоздаётся при старте. Полезные строки:
- `Микрофон: …` — какой вход используется;
- `· услышано: «…»` — что декодировал vosk (постоянный слушатель);
- `· перепроверка: «…»` / `✓ whisper подтвердил «зету»` — работа верификатора;
- `▸ «…»` — итоговая команда (whisper-medium);
- `→ окно ZCode найдено` / `→ общий диалог` — куда ушла команда.

Если «рабочая голова робота» не срабатывает — скажи слово пару раз и посмотри последние
строки лога: видно, как именно тебя слышит vosk и что отвечает whisper.

## Если сломалось

- Перезапуск — ярлык на рабочем столе (старый процесс закрыть из трея).
- `pip install -r requirements.txt` в `.venv` (важно: `av<16`).
- Нейроголос молчит (edge-tts 403) — Microsoft капризничает, ответ всё равно
  прозвучит системным Irina.

## Голосовая команда «озвучь голосом ответ»

Скажи «голова робота, озвучь голосом ответ» — команда придёт в чат агенту,
и он прочитает свой последний ответ вслух (нейроголос; Markdown вычищается,
код пропускается). Скрипт озвучки: `speak.py` (текст аргументом, из файла
или со stdin).

## Голосовая команда «стоп»

«Голова робота стоп» (а также «замолчи», «хватит», «останови озвучку»)
мгновенно глушит любую озвучку: и озвучку ответов агентом (speak.py),
и голос скрытого ассистента. Команда перехватывается демоном и в чат
не уходит. Обычные команды со словом «стоп» внутри (например,
«стоп открой файл») проходят агенту как обычно.

## Голосовая команда «новое окно»

«Голова робота новое окно» (или «новый диалог» / «новая сессия» / «новая
задача») — открывает в приложении ZCode новый пустой диалог (Ctrl+N,
«New task»). Приложение одновиндовое: новый диалог открывается в том же
окне, прежний остаётся в списке слева. Если сказать «новое окно, <текст>» —
текст станет первым сообщением нового диалога.
