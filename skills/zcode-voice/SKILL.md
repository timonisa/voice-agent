# Голосовой интерфейс ZCode

На машине может быть установлен голосовой демон (проект `~/voice-zcode`,
запускается из трея как «Голосовой ZCode»). Он слушает микрофон, ждёт фразу
**«рабочая голова робота»** (или слово «зета»), распознаёт команду локальным
whisper-medium и **вставляет текст прямо в поле ввода ZCode** — то же окно,
тот же диалог, что и печатный ввод. Если ZCode не запущен — команда уходит
скрытому голосовому агенту, ответ озвучивается.

## Голосовые команды демона (в чат НЕ приходят, перехватываются до отправки)

| Фраза после «рабочая голова робота» | Действие |
|---|---|
| «стоп» / «замолчи» / «хватит» | мгновенно глушит любую озвучку |
| «новое окно [, текст]» | новый диалог (Ctrl/Cmd+N); текст после запятой — его первое сообщение |

Синонимы «нового окна»: «новый диалог», «новая сессия», «новая задача».
Обычные фразы со словом «стоп» внутри («стоп открой файл») проходят агенту.

## Команды, которые приходят агенту (как обычные сообщения)

- «озвучь голосом ответ» / «прочитай ответ» / «зачитай последний ответ»:
  1. возьми СВОЙ предыдущий ответ (последнее сообщение ассистента перед
     командой); если его нет — скажи, что озвучивать нечего;
  2. очисти от Markdown (звёздочки/решётки/бэктики/таблицы убрать; списки
     читать как «во-первых… во-вторых»; код НЕ читать — сказать «фрагмент
     кода пропускаю» и назвать файл; ссылки — «ссылка в чате»);
  3. длиннее ~1000 символов — озвучь начало и закончи «…и так далее»;
  4. запусти озвучку (текст — во временный файл в UTF-8, кириллица через
     аргументы ломается):
     ```
     printf '%s' "$TEXT" > /tmp/speak.txt
     "$HOME/voice-zcode/.venv/bin/python3" "$HOME/voice-zcode/speak.py" /tmp/speak.txt
     ```
     (на Windows путь: `%USERPROFILE%\voice-zcode\.venv\Scripts\python.exe`;
     нейроголос, офлайн-фолбэк — системный голос Irina/`say`);
  5. в чате ответь одной строкой: «Озвучил.»
- Просьба ответить «голосом» / «озвучить» что-то другое — тот же скрипт
  `speak.py` (или `say.cmd`/`say.sh` для быстрого системного голоса).

Если «стоп» пришёл ТЕКСТОМ во время озвучки — погаси проигрывание:
Windows: останови процессы, чья командная строка содержит `speak.py`
(Stop-Process через Get-CimInstance Win32_Process);
macOS: `pkill -f speak.py`.
Затем ответь «Замолчал.»

## Установка на новую машину (см. инструкцию на флешке)

Windows: `install.cmd`; macOS: `install.sh` (нужны python3 и разрешение
«Универсальный доступ/доступ к вводу» для Терминала). Детали — в файле
«Инструкция по установке.md» рядом с этим навыком.

## Диагностика

Лог `~/voice-zcode/voice.log` пересоздаётся при старте демона:
- `Микрофон: …` — какой вход используется;
- `· услышано: «…»` — что декодировал постоянный слушатель (vosk);
- `· перепроверка: «…»` / `✓ whisper подтвердил` — двухступенчатый wake;
- `▸ «…»` — итоговая команда; `→ … вставляю` / `→ общий диалог` — маршрут;
- `✓ вставлено` — текст дошёл до поля ввода ZCode.

Голосовые сообщения пользователя — обычные сообщения: обрабатывай их как
обычный запрос. Фразу «рабочая голова робота» в начале текста игнорируй — это
слово-активатор.
