# Голосовой интерфейс ZCode — установка на другой компьютер

Комплект для переноса: голосовое управление ZCode фразой «личная голова робота»,
олицетворённый диалог (текстом и голосом в одно окно), озвучка ответов.

## Что на флешке

```
install.cmd                ← автоустановка для Windows
install.sh                 ← автоустановка для macOS
Инструкция по установке.md ← этот файл
voice-zcode\               ← сам проект (код, vosk-модель, настройка)
skills\zcode-voice\        ← навык для агента (скопируется автоматически)
```

## Требования

- Установленное приложение ZCode, **пользователь залогинен** (креды демон
  подхватит сам из конфига приложения).
- Микрофон и динамики.
- Интернет на первый запуск (скачает whisper-medium ~1.5 ГБ; дальше
  распознавание полностью локальное).

## Windows

1. Скопируй всю флешку в любую папку.
2. Запусти `install.cmd` (двойной клик). Он: скопирует проект в
   `%USERPROFILE%\voice-zcode`, поставит Python 3.12 (winget, per-user),
   создаст окружение, скопирует навык агенту, сделает ярлыки на рабочем
   столе и в автозапуске.
3. Запусти «Голосовой ZCode» — в трее появится синий значок с микрофоном.
4. Скажи: **«личная голова робота, привет»** — сообщение появится в текущем
   диалоге ZCode.

## macOS (MacBook)

1. Скопируй всю флешку, открой Терминал в папке копии и выполни:
   `bash install.sh`
   (нужен python3: `brew install python` или с python.org)
2. Разреши в **Системных настройках → Конфиденциальность и безопасность**:
   - **Микрофон** — Терминалу (и/или Python);
   - **Универсальный доступ** — Терминалу (нужно для вставки Cmd+V);
   - **Мониторинг ввода** — Терминалу (нужно для хоткея).
   macOS спросит сама при первом срабатывании — но лучше разрешить сразу.
3. Демон стартует сразу и добавится в автозагрузку (LaunchAgent).
   Ярлык для ручного запуска: `voice-zcode/start-voice.command`.
4. Хоткей на маке: **⌘+Option+Пробел** (зажать — говорить — отпустить).

Важно про macOS: эта ветка написана и проверена только синтаксически
(рабочая машина была Windows) — если что-то не заведётся, смотри лог
`~/voice-zcode/voice.log` и раздел «Если не работает» ниже; там же лежит
навык агенту, попроси его разобраться — он умеет.

## Голосовые команды

| Фраза | Действие |
|---|---|
| «личная голова робота, …» | команда в текущий диалог ZCode (текстом и голосом в один диалог) |
| «личная голова робота стоп» / «замолчи» | мгновенно глушит озвучку |
| «личная голова робота новое окно [, текст]» | новый диалог (Ctrl/Cmd+N) |
| «озвучь голосом ответ» | агент читает вслух свой последний ответ |
| хоткей (Win: Ctrl+Alt+Пробел / Mac: ⌘+Option+Пробел) | зажать — говорить — отпустить |

Если ZCode не запущен — команды уходят скрытому голосовому ассистенту,
ответы озвучиваются.

## Если не работает

- **Не слышит «личная голова робота»**: скажи чётче; смотри `voice.log` — строки
  «· услышано: …» показывают, что реально слышит микрофон; сомнительные
  фразы перепроверяет whisper (строки «· перепроверка»).
- **Не вставляется в окно**: на Windows демон сам разворачивает окно и
  фокусирует поле ввода; проверь, залогинен ли ZCode. На macOS убедись,
  что Терминалу дан «Универсальный доступ».
- **Нет нейроголоса**: edge-tts иногда отдаёт 403 — ответ всё равно
  прозвучит системным голосом (Windows: Irina; macOS: say).
- **Модели**: whisper качается в `~/voice-zcode/models` при первом запуске;
  vosk-модель лежит на флешке уже распакованной.

## Что внутри (для агента-получателя)

Полная документация — `voice-zcode/README.md`, устройство и команды —
в навыке `skills/zcode-voice/SKILL.md` (после установки он лежит в
`~/.zcode/skills/zcode-voice/`). Настройки — `voice-zcode/settings.json`
(слово-активатор, хоткей, микрофон, модель, таймауты).
